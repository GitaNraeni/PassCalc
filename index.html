Tutorial Membuat Game Pass

  1. Buka create.roblox.com.
  2. Pilih game kamu → Associated Items → Game Passes → Create Pass.
  3. Upload gambar, isi nama & deskripsi.
  4. Configure → Sales → aktifkan Item for Sale → isi harga kalkulator → matikan Regional Pricing → Save.
